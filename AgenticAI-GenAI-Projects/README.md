# Agentic AI & Generative AI Projects

This directory is the project workspace for Generative AI and Agentic AI development within DSGAAP.

It is intended to contain practical projects, experiments, examples, notebooks, source code, and supporting documentation built with Python and related AI technologies.

---

## 🎯 Purpose

This area is designed for:

- Generative AI projects
- Agentic AI projects
- Python-based AI applications
- LLM experiments and prototypes
- Agent workflows and orchestration
- Retrieval-Augmented Generation (RAG) projects
- API and model integration examples
- Jupyter-based experimentation
- Reusable examples and learning projects

## 📂 Project Structure

Initially:

```text
AgenticAI-GenAI-Projects/
│
└── README.md
```

As projects are introduced:

```text
AgenticAI-GenAI-Projects/
│
├── README.md
│
├── <project-01>/
│   ├── README.md
│   ├── notebooks/
│   └── src/
│
├── <project-02>/
│   ├── README.md
│   └── src/
│
└── ...
```

The exact structure of each project should reflect its requirements rather than forcing every project into the same layout.

---

## 📝 Project Documentation

Each substantial project should include its own `README.md` describing, where applicable:

- Project purpose
- Problem being solved
- Architecture or approach
- Prerequisites
- Environment and dependencies
- Setup instructions
- How to run the project
- Configuration requirements
- Examples
- Known limitations
- Troubleshooting notes

> Do not store machine-specific credentials, secrets, API keys, or tokens in project documentation or source control.

---

## 🧪 Development Approach

Projects in this directory should favor:

- Clear and readable Python
- Isolated project dependencies
- Reproducible examples
- Incremental experimentation
- Documented configuration
- Meaningful validation
- Reusable components where appropriate
