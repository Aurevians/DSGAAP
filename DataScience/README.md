# Data Science

This directory is reserved for the Data Science learning and project journey within DSGAAP.

The Data Science journey has not started yet. This area is established now so the repository can grow without requiring a future structural redesign.

---

## 🎯 Purpose

When Data Science learning begins, use this area for:

- Data analysis
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Data visualization
- Statistics and probability
- NumPy and pandas
- Jupyter notebooks
- Machine learning foundations
- Data Science experiments
- Structured Data Science projects

Daily learning notes belong in [Learning Notes](../Learning-Notes/README.md).

---

## 📂 Structure

```text
DataScience/
│
├── README.md
├── Practice/
│   └── <topic-folders-and-practice-files>/
└── Projects/
    └── <data-science-projects>/
```

> Git does not track empty directories. `Practice/` and `Projects/` will appear after their first file is added.
