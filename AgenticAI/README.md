# Agentic AI

This directory contains Agentic AI learning, experimentation, practice, and structured projects within DSGAAP.

It provides a dedicated workspace for building systems in which AI models can use tools, maintain context or memory, follow workflows, coordinate tasks, and participate in more autonomous or orchestrated application patterns.

---

## 🎯 Purpose

Use this area for topics such as:

- Agentic AI fundamentals
- AI agents
- Tool and function calling
- Agent memory and state
- Planning and reasoning workflows
- Agent orchestration
- Multi-agent systems
- Human-in-the-loop workflows
- Agent evaluation and observability
- Agent framework experimentation
- Agentic AI applications

Daily learning notes belong in [Learning Notes](../Learning-Notes/README.md).

---

## 📂 Structure

```text
AgenticAI/
│
├── README.md
├── Practice/
│   └── <practice-and-experiments>/
└── Projects/
    └── <agentic-ai-projects>/
```

> Git does not track empty directories. `Practice/` and `Projects/` will appear after their first file is added.

---

## 🧪 Practice

Use `Practice/` for agent exercises, tool-calling experiments, workflow experiments, framework exploration, notebooks, and proof-of-concept code.

---

## 🏗️ Projects

Use `Projects/` for structured Agentic AI applications.

Each substantial project should normally include its own `README.md` covering its purpose, architecture, agents and tools, dependencies, setup, configuration, execution, examples, and known limitations.

> Do not store credentials, secrets, API keys, or tokens in source control.
