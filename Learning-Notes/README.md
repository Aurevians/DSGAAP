# Learning Notes

This directory is the learning journal for DSGAAP.

Use it for daily notes, concepts, observations, useful commands, references, questions, lessons learned, and key takeaways across Python, Data Science, Generative AI, and Agentic AI.

---

## 🎯 Purpose

Use this area to capture:

- Topics covered during a learning session
- Important concepts and explanations
- Useful commands and syntax
- Questions to revisit
- Mistakes and lessons learned
- References worth keeping
- Key takeaways
- Connections between different areas

Executable practice should remain with the relevant subject:

- [Python Practice](../Python/Practice/)
- [Data Science Practice](../DataScience/Practice/)
- [Generative AI Practice](../GenerativeAI/Practice/)
- [Agentic AI Practice](../AgenticAI/Practice/)

---

## 📂 Suggested Structure

```text
Learning-Notes/
│
├── README.md
│
└── 2026/
    └── 08-August/
        ├── 2026-08-06.md
        ├── 2026-08-07.md
        └── ...
```

Using `YYYY-MM-DD.md` keeps daily notes naturally sorted chronologically.

---

## 📝 Suggested Daily Note Format

```markdown
# YYYY-MM-DD

## Topics Covered

- Topic 1
- Topic 2

## What I Learned

Notes and explanations from today's learning.

## Practice

Links to relevant practice files or notebooks.

## Key Takeaways

- Takeaway 1
- Takeaway 2

## Questions / Revisit

- Concept or question to revisit.

## References

- Relevant documentation or resource.
```

The format is intentionally flexible; not every section needs to be used every day.
