# Generative AI

This directory contains Generative AI learning, experimentation, practice, and structured projects within DSGAAP.

It provides a dedicated workspace for understanding and building applications around large language models and other generative AI capabilities before progressing into more advanced agentic systems.

---

## 🎯 Purpose

Use this area for topics such as:

- Generative AI fundamentals
- Large Language Models (LLMs)
- Prompt engineering
- Model APIs and integrations
- Embeddings
- Vector databases
- Retrieval-Augmented Generation (RAG)
- Structured outputs
- LLM evaluation
- Generative AI experiments
- Generative AI applications

Daily learning notes belong in [Learning Notes](../Learning-Notes/README.md).

---

## 📂 Structure

```text
GenerativeAI/
│
├── README.md
├── Practice/
│   └── <practice-and-experiments>/
└── Projects/
    └── <generative-ai-projects>/
```

> Git does not track empty directories. `Practice/` and `Projects/` will appear after their first file is added.

---

## 🧪 Practice

Use `Practice/` for focused learning exercises, notebooks, API experiments, prompt experiments, RAG exercises, and proof-of-concept code.

Organize topic folders only as the amount of content grows.

---

## 🏗️ Projects

Use `Projects/` for structured Generative AI applications.

Each substantial project should normally include its own `README.md` covering its purpose, architecture, dependencies, setup, configuration, execution, examples, and known limitations.

> Do not store credentials, secrets, API keys, or tokens in source control.
