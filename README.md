# DSGAAP

## Data Science, Generative AI & Agentic AI with Python

DSGAAP is a central repository for Data Science, Generative AI, Agentic AI, Python development projects, learning resources, and developer environment documentation.

The repository is designed to keep projects and supporting documentation organized while making development environments reproducible, consistent, maintainable, and easier to troubleshoot across the team.

---

## 📚 Repository Areas

| Area | Description |
| --- | --- |
| [Installation Documentation](./Installation-Docs/README.md) | Installation, configuration, validation, troubleshooting, and developer environment setup guides. |
| [Agentic AI & GenAI Projects](./AgenticAI-GenAI-Projects/README.md) | Projects, experiments, examples, and supporting material related to Generative AI and Agentic AI development. |

Additional areas can be introduced as the repository grows.
