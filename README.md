# DSGAAP

## Data Science, Generative AI & Agentic AI with Python

DSGAAP is a central repository for learning, practicing, and building with Python, Data Science, Generative AI, and Agentic AI.

The repository keeps developer setup documentation, learning notes, hands-on practice, and structured projects clearly separated while providing a consistent structure that can grow over time.

---

## 📚 Repository Areas

| Area | Description |
| --- | --- |
| [Installation Documentation](./Installation-Docs/README.md) | Installation, configuration, validation, troubleshooting, and developer environment setup guides. |
| [Learning Notes](./Learning-Notes/README.md) | Daily learning notes, concepts, observations, references, questions, and key takeaways across the learning journey. |
| [Python](./Python/README.md) | Python fundamentals, hands-on practice, exercises, notebooks, and projects. |
| [Data Science](./DataScience/README.md) | Data Science learning, analysis, notebooks, practice, and projects. |
| [Generative AI](./GenerativeAI/README.md) | Generative AI concepts, LLM experimentation, prompting, embeddings, RAG, model integrations, practice, and projects. |
| [Agentic AI](./AgenticAI/README.md) | AI agents, tools, memory, orchestration, workflows, multi-agent systems, practice, and projects. |
