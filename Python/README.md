# Python

This directory contains Python learning material, hands-on practice, exercises, notebooks, and projects within DSGAAP.

Python provides the programming foundation for the broader Data Science, Generative AI, and Agentic AI journey.

---

## 🎯 Purpose

Use this area for:

- Python fundamentals
- Syntax and language concepts
- Hands-on exercises
- Jupyter notebooks
- Small experiments
- Problem-solving practice
- Reusable Python examples
- Python projects

Daily learning notes and reflections belong in [Learning Notes](../Learning-Notes/README.md).

---

## 📂 Structure

```text
Python/
│
├── README.md
├── Practice/
│   └── <topic-folders-and-practice-files>/
└── Projects/
    └── <python-projects>/
```

> Git does not track empty directories. `Practice/` and `Projects/` will appear after their first file is added.

---

## 🧪 Practice

Use `Practice/` for exercises, examples, notebooks, and experiments created while learning Python.

Possible topic folders can be introduced as they are reached:

```text
Practice/
├── Basics/
├── Data-Structures/
├── Functions/
├── OOP/
├── Exceptions/
├── File-Handling/
└── ...
```

There is no need to create these folders in advance.

---

## 🏗️ Projects

Use `Projects/` for structured Python applications built from concepts learned during practice.

Each substantial project should have its own directory and `README.md`.
